# Varzan website

Static homepage for Varzan (varzan.co), built by Mansha Studios.

- `index.html` is the whole site: markup, styles, scripts and photos (embedded).
- `clips/` holds the three scroll films: `clip2.mp4` (hero), `clip1.mp4` (the house behind the product), `dress.mp4` (signature pieces).

No build step. Deploy the folder as-is.
